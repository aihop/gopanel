# GoPanel 桌面端

桌面端使用 Wails 2 封装现有 Vue 管理台，并继续复用 Fiber HTTP API 和 WebSocket 实时通道。

## 构建

macOS、Linux 或 Windows 应在对应系统上原生构建：

```bash
./build-desktop.sh
```

指定目标平台时，将 Wails 参数直接传给脚本：

```bash
./build-desktop.sh -platform darwin/arm64
```

macOS 产物位于 `desktop/build/bin/GoPanel.app`，Bundle ID 为 `io.aihop.gopanel`。

## 运行模型

- 桌面窗口通过 Wails 加载现有前端产物。
- 启动时可连接已有 GoPanel Web 服务；远程模式只做代理，不打开本地数据库和缓存。
- 远程服务开启安全入口时，可单独填写入口或直接粘贴完整入口 URL；桌面网关会校验并自动携带入口凭据。
- 也可启动内置 Fiber 服务；内置模式优先使用配置端口，冲突时选择可用端口，并生成手机局域网地址。
- 当前连接和最近使用的服务器保存在 `~/.gopanel/desktop.json`，可从应用“连接”菜单打开服务器连接中心进行新增、编辑、删除和切换。
- 管理台空白区域的右键菜单提供刷新、前进/后退、返回首页、复制当前地址和打开连接中心；输入框、文本选择、代码编辑器和终端继续使用原生或组件自己的右键菜单。
- 窗口标题及“连接”菜单持续显示当前模式、地址和在线状态；连接中心会在切换前验证目标身份与安全入口。
- 切换服务器后会清理上一台服务器的登录态、CSRF 和安全入口缓存，避免跨服务器复用认证；主题和语言设置继续保留。
- 配置、数据库和日志写入 `~/.gopanel`，与现有 GoPanel 默认数据目录保持一致。
- 首次启动会创建 `admin@gopanel.local` 管理员，并通过原生对话框显示随机临时密码；登录后应立即修改密码。
- 关闭窗口时会停止 AI 执行任务并优雅关闭 HTTP 服务。
- 桌面窗口默认 `1280×800`，最小 `900×600`；隐藏可见滚动条但保留触控板、滚轮和键盘滚动。

当前 macOS 构建使用 ad-hoc 自签名；正式分发仍需配置 Apple Developer ID 签名与公证。
